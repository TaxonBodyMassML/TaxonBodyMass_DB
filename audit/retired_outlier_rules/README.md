# Retired outlier rule files

Retired on 2026-10-03 (issue #24, owner decision). Nothing in this directory
is sourced by the pipeline; the files are kept as the record of the 2026-08
outlier review.

## What the files were

`fix_outliers.r` (`FixOutliers()`, 242 `RemoveRecord()` rules) and
`fix_outliers_multisource.r` (`FixOutliersMultiSource()`, 30 `RemoveSource()`
rules) were generated by Claude on 2026-08-25 from its review of outlying
body-mass values. The single-source file deletes the records of taxa whose only
value looked implausible, in two tiers (highly suspect, `../outlier_report.md`;
suspicious, `../outlier_report_2.md`); the multi-source file removes, for taxa
present in two or more sources, the value of the one source that disagreed with
the others. Each rule's comment quotes the value the source held that day
(`# <value> g → <expected> g` in the single-source file, `<Source>=<value>` in
the multi-source file). Both files lived in `R/library/` and were applied in
`R/RunMe.r` (section 2b) only under `FixOutlierValues <- TRUE`. The flag was
`FALSE` in every committed version of the pipeline (its comment: "list and
fixes generated by Claude, so better to distrust and remove records"), so no
published output ever reflected them.

## Why they were retired

The rules describe source values as they stood on 2026-08-25. Many of those
values have since been corrected or removed in the parse scripts (#7
McCoy_2008, #8 imputed rows and the FoRAGE cache, #13 DeLong 2010 units, #15
AnAge, the 2026-09-24 lifestage filters, live FishBase snapshots), so a rule
written for one value would now delete another. `audit_outlier_rules.R`, run on
2026-10-03 against `sources/Rdata/` regenerated at main 39dd7fd (output:
`outlier_rules_audit_2026-10-03.csv`), compared each rule's quoted value with
the current geometric mean of that taxon x source:

| status | rules |
| --- | ---: |
| still matches the quoted value (within 1 %) | 175 |
| record gone (taxon no longer in that source) | 50 |
| value changed by more than 1 % | 24 |
| source label no longer exists in any frame | 13 |
| present, but no quoted value could be parsed from the comment | 10 |
| **total** | **272** |

The clearest case: all 16 DeLong_etal_2010 rules (13 `RemoveSource()`, 3
`RemoveRecord()`) target the sd02 metazoan rows whose µg values had been read
as g, which #13 corrected; under `FixOutlierValues = TRUE` the corrected values
(Gadus morhua 15 kg, Hippoglossoides platessoides 277 g, Eurycercus
longirostris 71 µg, ...) would have been deleted again. Rather than add a
staleness guard and re-review the 97 stale rules for a mechanism that had never
been switched on, the owner retired it (issue #24, comment of 2026-10-03). The
two files were moved here unchanged (`git mv`, history preserved); the flag, the
two `source()` lines, the `if (FixOutlierValues)` block and the
`RemoveSource()`/`RemoveRecord()` helpers in `R/library/helpers.r` were
removed.

## How single-record corrections are handled now

A wrong value for a particular taxon is corrected in the lab Google Sheet
(`BodyMassCompilation`, tab `BM_data`), which `R/RunMe.r` reads in section 4
("Lab Google Sheet override"): a curated row replaces all compiled records for
that taxon. `../outlier_corrections_single_source.md` documents the 2026-08
single-source findings; the hand-confirmed corrections among them were entered
in that tab. Systematic problems with a source (units, imputed rows, life
stages) are fixed in its parse script under `sources/databases/<Source>/`, and
taxa whose sources disagree by more than an order of magnitude are still
dropped from the output by `RemoveHighMaxMinRatio`
(`R/library/remove_high_range.r`).

## Files

- `fix_outliers.r`, `fix_outliers_multisource.r` -- the rule files as they were
  at main 39dd7fd (the eight `Pauly_2024` rules were relabelled
  `GuoBailly_2024` by PR #22).
- `audit_outlier_rules.R` -- the staleness audit; run
  `Rscript audit/retired_outlier_rules/audit_outlier_rules.R` from the
  repository root with a complete `sources/Rdata/`.
- `outlier_rules_audit_2026-10-03.csv` -- its output, one row per rule
  (`file, line, fun, taxon, source, quoted, cur_gm, n_rows, label_exists,
  status`).
- Review documents: `../outlier_report.md` (CRITICAL tier),
  `../outlier_report_2.md` (SUSPICIOUS tier),
  `../outlier_corrections_single_source.md` (per-record corrections and
  rationale), `../flagged_species.csv` (the 2,082 model-flagged records).
