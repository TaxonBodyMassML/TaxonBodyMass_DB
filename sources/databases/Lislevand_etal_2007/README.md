# Lislevand, Figuerola & Székely (2007) avian body sizes (Ecological Archives E088-096)

## Data

Source: Lislevand, T., Figuerola, J., & Székely, T. (2007) Avian body sizes in relation to fecundity, mating system, display behavior, and resource sharing. Ecology 88:1605 (Ecological Archives E088-096, data paper). https://doi.org/10.1890/06-2054. Bib key `Lislevand:2007aa` (`Citation.bib`; also in `Bib/TaxonBodyMass_Citations.bib`, without a `doi` field).
Data: `avian_ssd_jan07.txt` (the archive's data file: tab-separated, CR line endings, 3,769 rows x 41 columns, one row per species or subspecies; `-999` for missing values), `metadata.htm` and `default.htm` (the archive's metadata and landing pages, saved as downloaded). Columns: `Family` (an integer family code resolved in the metadata), `Species_number`, `Species_name`, `English_name`, `Subspecies`, male / female / unsexed body mass, wing, tarsus, bill and tail length with their sample sizes (`M_mass`, `M_mass_N`, ...), `Clutch_size`, `Egg_mass`, `Mating_System`, `Display`, `Resource`, `References` (';'-separated numbers into the reference list of the metadata, section F, cited for the whole row).

Columns used: `Species_name`, `M_mass`, `F_mass`, `unsexed_mass`, `Family`, `References`.
Filters: `-999` read as missing; the record's mass is the arithmetic mean of the male, female and unsexed masses given; rows without any of the three are dropped. `n = 1`. Known limitation (left as it is in this round, owner item of 2026-10-05): `read.table()` runs with its default quoting, and 369 English names contain an apostrophe (`Pallas's Sandgrouse`), so only 1,739 of the 3,769 rows are read (the rows between two apostrophes collapse into one field) and 1,613 records are kept, where the full file holds 3,440 rows with at least one mass. The same file reaches the pipeline a second time through the DataRetriever `bird-size` dataset (`R/library/data_retrieve.r`, label `Lislevand_etal_2007` too, male mass only, 2,818 species, no `ref_keys`): 1,276 species are in both frames, 337 only here, 1,542 only in the DataRetriever frame; the two frames are averaged within the label by the pipeline.
Mass type: body mass in grams (mean of the sex-specific and unsexed means reported); no conversion.
Imputed rows: none flagged in source (the archive compiles published species means and the authors' unpublished measurements).

## Provenance
