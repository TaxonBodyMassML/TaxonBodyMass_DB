# Lislevand, Figuerola & Székely (2007) avian body sizes (Ecological Archives E088-096)

## Data

Source: Lislevand, T., Figuerola, J., & Székely, T. (2007) Avian body sizes in relation to fecundity, mating system, display behavior, and resource sharing. Ecology 88:1605 (Ecological Archives E088-096, data paper). https://doi.org/10.1890/06-2054. Bib key `Lislevand:2007aa` (`Citation.bib`; also in `Bib/TaxonBodyMass_Citations.bib`, without a `doi` field).
Data: `avian_ssd_jan07.txt` (the archive's data file: tab-separated, CR line endings, 3,769 rows x 41 columns, one row per species or subspecies; `-999` for missing values), `metadata.htm` and `default.htm` (the archive's metadata and landing pages, saved as downloaded). Columns: `Family` (an integer family code resolved in the metadata), `Species_number`, `Species_name`, `English_name`, `Subspecies`, male / female / unsexed body mass, wing, tarsus, bill and tail length with their sample sizes (`M_mass`, `M_mass_N`, ...), `Clutch_size`, `Egg_mass`, `Mating_System`, `Display`, `Resource`, `References` (';'-separated numbers into the reference list of the metadata, section F, cited for the whole row).
Licence: no copyright restrictions (Ecological Archives) (in-file: `metadata.htm` "Copyright restrictions: None. Proprietary restrictions: None. Costs: None, the authors believe that scientific data should be free for scientific use."; https://doi.org/10.1890/06-2054). The data file and the two htm files are tracked and redistributed with attribution to the data paper; the reference tables are ours.

Columns used: `Species_name`, `M_mass`, `F_mass`, `unsexed_mass`, `Family`, `References`.
Filters: `-999` read as missing; the record's mass is the arithmetic mean of the male, female and unsexed masses given; rows without any of the three are dropped. `n = 1`. 3440 records of 3439 species names (*Ardea picata* has a nominate and a subspecies row, pooled by the pipeline). The file is read with `quote = ""` (issue #102, 2026-10-05): until then `read.table()` ran with its default quoting, and the apostrophes of 369 English names (`Pallas's Sandgrouse`) swallowed the rows between two of them into one field, so only 1,739 of the 3,769 rows were read, 1,613 records kept, and 134 of those carried a value from a shifted column (rows that followed a swallowed span; *Bucephala islandica* 18 g for 910 g), 23 of them for species the file gives no mass for. Until the same day the file also reached the pipeline through the DataRetriever `bird-size` dataset (`R/library/data_retrieve.r`, same label, male mass only, no reference numbers, 2,822 rows); that fetch is removed (#102) and this parser is the label's only source.
Mass type: body mass in grams (mean of the sex-specific and unsexed means reported); no conversion.
Imputed rows: none flagged in source (the archive compiles published species means and the authors' unpublished measurements).

## Provenance

Provenance: compilation (`Bib/source_provenance_classes.csv`: class `compilation`, default type `unknown`); record-level, hop 1 through the `References` column kept as `ref_keys` (`SplitRefKeys(adat$References, ';')`; ';'-separated numbers, up to 8 per row, one row with a trailing separator `1; 7; 16; 19; ` whose empty token is dropped; 3440 of 3440 records keyed, 2529 with more than one key, 84 distinct keys). The numbers are cited for the whole row of the data file -- body masses, lengths, egg mass, clutch size and the behavioural scores alike -- so a record may carry a reference that supports another of its variables: 31 (Schönwetter's Handbuch der Oologie, 2,235 kept records) is an egg handbook and is `drop`ped by owner decision (its records cite the compilation), and 1 (Dunn et al. 2001, 1,023 records) is a mating-system compilation of more than 1,000 species, kept with role `compilation`. Reference list `references.csv` (`key`, `citation`; 87 numbered entries, verbatim from the HTML table of `metadata.htm` section F, written by `build_references.py`; the metadata's `1-89` range and the registry's earlier `~117` were wrong); entries 71, 83 and 86 are cited by no kept record.
