# Ernest (2003) life history characteristics of placental nonvolant mammals

Source: Ernest, S. K. M. (2003) Life history characteristics of placental nonvolant mammals. Ecology 84:3402. Ecological Archives E084-093. DOI 10.1890/02-9002.
Data: fetched at run time by rdataretriever (mammal-life-hist dataset; nothing stored in this folder; see `sources/databases/DataRetriever/README.md`).
Licence: CC BY 4.0 (Ecological Archives; https://esapubs.org/archive/ecol/E084/093/; covered by the DataRetriever live-row entry in source_files.csv). The tracked primary_references.csv is our own working table (repository licence).

Columns used: `genus` + `species`, `mass_g`, `family`.
Filters: positive masses only (mass_g > 0 and non-NA); Latin binomials from genus + species; no lifestage filter (all records treated as adult measurements).
Mass type: wet mass in grams, as reported in the mammal-life-hist dataset.
Source label: 'Ernest_2003'.
Imputed rows: none (no imputation or method flag in the source; all mass_g values are taken as reported).
