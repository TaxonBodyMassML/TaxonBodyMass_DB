The main dataset containing available experimental studies that report ciliate species, ciliate cell volumes, 
ciliate growth rates and experimental temperatures can be found in 'Dataset_v2.lsx' file. This is the main document.

More details/clarifications about each column of the main document can be found in 'Units_table.xlsx' file.

Details on the references - i.e. authors, publication year, title, journal, volume and page/article numbers - 
used to compile this dataset can be found in 'References.xlsx'
