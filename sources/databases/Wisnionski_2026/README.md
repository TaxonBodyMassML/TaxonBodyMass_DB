# Wisnionski et al. (2026) corticosterone, metabolic rate and body mass of reptiles, birds and mammals

## Data

Source: Wisnionski, A. R., Haase, C. G., Dy, I., Hudson, K., & Gillooly, J. F. (2026) Corticosterone concentration varies with metabolic rate in vertebrates. Ecology and Evolution 16(9):e74243. https://doi.org/10.1002/ece3.74243 (published 2026-08-27, CC BY 4.0 according to the Crossref record). Bib key `Wisnionski:2026aa` (`Citation.bib`, the owner's BibDesk entry; it carries no DOI field).
Data: Dryad dataset https://doi.org/10.5061/dryad.79cnp5jbt ("Data and code from: Corticosterone concentration varies with metabolic rate in vertebrates"; its `README.md` is kept here as `README_dryad.md`). The workbook `VertData.xlsx` has one sheet per class; the owner exported them as `VertData_reptiles.csv` (48 rows), `VertData_birds.csv` (82) and `VertData_mammals.csv` (34), downloaded 2026-10-04. Columns: `Species Name`, `Common Name`, `Sex`, `n` (individuals sampled for corticosterone), `Season`, `Life Stage`, `Lifespan` (yr), `Body Mass` (g; `Body Mass_g` in the reptile file), `MSMR`, `Basal CC`, `Basal Cortisol`, `Elevated CC`, `Time Range`, `Assay`, `Environment`, `Stressor`, plus `Temp` (reptiles) and `Dominant` (mammals). The Dryad README quotes 49 / 83 / 35 species; the files hold one row fewer per class. Supplement: `ece374243-sup-0001-supinfo.pdf` (Wiley Supporting Information of the CC BY article; the copy here is the owner's PDF rendering of 2026-10-05 of the Word supplement, 22 pages): Table S1 repeats every row with a bracketed reference number after the body mass, the metabolic rate and the lifespan and at the end of the row for the corticosterone study, then the numbered reference list 1-132, Figure S1, Table S2, Figure S2. `parse_wisnionski_supmat.py` (PyMuPDF) reads Table S1 into `TableS1_parsed.csv` (163 rows: 48 reptiles, 81 birds, 34 mammals; 161 with a mass; the per-value reference numbers, the juvenile `^` and serum `*` marks) and the reference list into `references.csv` (`key`, `citation`: the number and the verbatim entry; 8 entries carry no DOI).

Columns used: `Species Name`, `Body Mass` / `Body Mass_g`, `Life Stage`; the class of the file (Reptilia, Aves, Mammalia) is the taxonomy hint. `Lifespan`, `MSMR`, the hormone columns and `n` (a corticosterone sample size, not a mass sample size) are not used.
Filters: rows without a body mass are dropped (Egernia whitii, Phrynocephalus vlangalii); five juvenile rows are dropped through `DropImputed()` (below); trinomials are truncated to the binomial (Pituophis catenifer affinis, Thamnophis elegans vagrans, Thamnophis sirtalis parietalis, Canis lupus dingo, Mustela putorius furo). Every kept row must match a Table S1 row by name (24 names differ, see Provenance) and its mass must agree with the printed value within 0.5 g or 0.5 % (Table S1 rounds to the gram; the parser stops otherwise). 157 records of 157 species: 42 reptiles, 81 birds, 34 mammals.
Mass type: body mass in grams as compiled by the authors, one value per species; no conversion. The value is a species mean or handbook adult mass copied from a database or compilation on 99 of the 157 kept rows (AnAge 41, Dunning 1993 25, Bokony et al. 2009 27, Gillooly et al. 2017 4, White et al. 2006 2) and the mean mass of the sampled animals of the corticosterone study on the other 58 (Table S1). The data file's values are kept (e.g. 421.31 g where Table S1 prints 421). `n = 1`. Several species are domestic forms (Bos taurus, Ovis aries, Sus scrofa, Gallus domesticus 2,580 g, Cavia porcellus, Oryctolagus cuniculus 3,000 g, Mus musculus, Mesocricetus auratus, Columba livia, Mustela putorius furo, Canis lupus dingo).
Imputed rows: none flagged as imputed in the source. Five rows are juveniles or young of the year (`Life Stage` 'Juvenile', '3 months', '20 months'; the `^` mark of Table S1) whose mass is that of the animals of the corticosterone study, so they are not adult records and are dropped through `DropImputed()` (logged to audit/imputed_rows.csv): Alligator mississippiensis (792.8 g, Lance & Elsey 1999), Caiman latirostris (160.95 g, hatchlings of Ciocan et al. 2018), Crocodylus niloticus (540 g, Balment & Loveridge 1989), Lepidochelys kempii (4,300 g, Hunt et al. 2019) and Anas platyrhynchos (2,709 g, ducklings of Harvey & Phillips 1980; the value is far above a duckling's or an adult mallard's mass). No other row of these species is in the file, so the five species leave with them. The `Life Stage` 'Mix' row (Sturnus vulgaris) keeps Dunning's adult mass and is kept.

## Record set

Source label: `Wisnionski_2026`. 157 records (one per species), `class` per file. Table S1 and the data file disagree on 24 names; the data file's names are kept as the raw names and the parser maps them to Table S1 only to read the reference numbers: older synonyms (Cnemidophorus sexlineatus / uniparens = Aspidoscelis, Lacerta vivipara = Zootoca, Podarcis sicula = P. siculus, Carduelis flammea = Acanthis, Grus canadensis = Antigone, Melozone aberti = Kieneria, Parus caeruleus = Cyanistes, Peucaea carpalis = Aimophila, Rhynchophanes mccownii = Calcarius, Spizella arborea = Spizelloides, Macropus rufogriseus = Notamacropus, Egernia whitii = Liopholis, Gallus domesticus = G. gallus), abbreviated subspecies (Pituophis c. affinis, Thamnophis s. parietalis, Canis l. dingo, Mustela p. furo), two misspellings in the data file (Thallasarche melanophris, Thryesphilus rufalbus) and two genuine differences: the file's Crotalus helleri is Table S1's Crotalus viridis (Claunch et al. 2017, reference 26, studied Southern Pacific rattlesnakes), and the file's Thamnophis elegans vagrans is Table S1's Thamnophis errans (Neuman-Lee et al. 2020, reference 47, studied T. elegans). The data file holds two black-browed albatross rows, Diomedea melanophris 3,564 g and Thallasarche melanophris 3,540 g, which Table S1 merges into one row of 3,552 g cited to [56,102]; both rows are kept (the pipeline resolves both names to the same species) with the reference split as described below.

## Provenance

Provenance: compilation (`Bib/source_provenance_classes.csv`, default unknown); record-level, hop 1 through the mass reference number(s) of Table S1 kept as `ref_keys` (157 records, 0 NA, 53 distinct keys; one record with two keys would have been the albatross row, split instead), resolved in `references.csv` (132 entries, extracted verbatim from the supplement by `parse_wisnionski_supmat.py`; entries 14, 25, 56, 60, 84, 117, 122 and 124 print no DOI). The reference for the albatross rows: 3,564 g is Dunning's (1993) value (McCoy_2008 recovers the identical number from Dunning 1993), so that row keeps key 56 and the 3,540 g row keeps key 102 (Angelier et al. 2007). The compilations the masses are copied from are registered in `Bib/source_dependencies.csv` (added 2026-10-04): `Wisnionski_2026 -> AnAge` (reference 4, 41 rows; 31 shared with the AnAge Build 13 frame, 24 identical, 29 within 0.0105 log10 after rounding to the gram; Gallus domesticus and Elephas maximus differ; ten reptiles cited to AnAge have no adult weight in the Build 13 export), `-> Dunning_2008` (reference 56, Dunning 1993, 25 rows; the register's label for both editions of the handbook, as for McCoy_2008; the values match McCoy_2008's Dunning-1993 numbers, not AVONET's Dunning-2008 ones), `-> Bokony_2009` (reference 68, 27 rows; not a database source), `-> Gillooly_2017` (reference 7, 4 rows; values identical with the White et al. 2006 lineage in Hoehler_etal_2023 and Uyeda_etal_2017) and `-> White_2006` (reference 40, 2 rows). The other 58 kept records cite the corticosterone study that sampled the animals (48 distinct references), including reference 2 (ReptTraits) and 63 / 86 (Lasiewski & Dawson 1967, McKechnie & Wolf 2004), which Table S1 cites for lifespan and metabolic rate only and which therefore never appear among the mass keys.
