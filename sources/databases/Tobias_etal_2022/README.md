# AVONET (Tobias et al. 2022)

Source: Tobias, J. A. et al. (2022) AVONET: morphological, ecological and geographical data for all birds. Ecology Letters 25:581-597. https://doi.org/10.1111/ele.13898
Data: figshare 10.6084/m9.figshare.16586228, Supplementary dataset 1 (`AVONET_Supplementary_dataset_1.xlsx`, CC BY 4.0), downloaded 2026-09-27 from https://ndownloader.figshare.com/files/34480856.

Columns used: sheet `AVONET1_BirdLife` (BirdLife taxonomy, 11,009 species): `Species1`, `Mass` (g, species mean body mass), `Order1`, `Family1`.
Filters: rows with `Mass.Source` in {Inferred, EltonTraits_GenAvg, EltonTraits_Model} or with `Traits.inferred` containing "Body Mass" are excluded (inferred or genus-average masses). 10,184 species remain.
Mass type: wet (live) mass in grams; no conversion. Label `Tobias_2022` (shared with the Google-Sheet override rows).
Imputed rows: the 825 rows with `Mass.Source` Inferred, EltonTraits_GenAvg or EltonTraits_Model, or with 'Body Mass' in `Traits.inferred`, are excluded by the filter above; the 917 'DataFromSplit' rows (mass inherited through a taxonomic split) are kept pending issue #5.

Provenance (issue #1, Stage 2, round of 2026-10-05, `audit/provenance_rounds.md`): compilation (`Bib/source_provenance_classes.csv`, default unknown); record-level, hop 1 through the per-row mass source, kept as `ref_keys` by the parser (`SplitRefKeys(..., ';')`) and resolved in `references.csv` (columns `key`, `citation`; 46 rows) for the citation tooling (`reflist_specs$Tobias_2022`, folder `Tobias_etal_2022`, frame `Tobias_2022`). The key of a record is the `Mass.Source` code word defined in the Metadata sheet, except that 'Dunning' (8,543 rows) is written as the Mass_Sources key 'Dunning (2008)' (the Metadata defines it as the 2008 CRC Handbook; one Updated_literature row cites 'Dunning (2008)' directly), and that the 'Updated_literature' (670 rows) and 'Updated_live.sample' (45 rows) rows take their `Mass.Refs.Other` text instead: the Citation keys of the Mass_Sources sheet ('; '-separated when a row cites two, *Accipiter tachiro* 'Jackson (1972); Dunning (2021)') or the team's own 'Live sample (museum data)' / 'Live sample (field data)'. `references.csv` holds the 42 Mass_Sources rows verbatim (Citation -> `key`, Full Reference -> `citation`, runs of blanks collapsed) plus four rows for the code keys, with the Metadata definition as citation text: 'EltonTraits_Other' (9 rows; Wilman et al. 2014, the EltonTraits paper's own citation with its DOI, so that hop 2 reaches `Wilman_etal_2014`), 'DataFromSplit' (917 rows; the parent species' mass, not a work) and the two 'Live sample' keys (45 rows, role `self`: the team's own museum-label and field weights).
