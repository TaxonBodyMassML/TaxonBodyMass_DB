# AmphiBIO v1 (Oliveira et al. 2017) amphibian body masses

Source: Oliveira, B. F., Sao-Pedro, V. A., Santos-Barrera, G., Penone, C., & Costa, G. C. (2017) AmphiBIO, a global database for amphibian ecological traits. Scientific Data 4:170123. https://doi.org/10.1038/sdata.2017.123
Data: `AmphiBIO_v1.csv` (the database), `AmphiBIO_v1_references.csv`, `AmphiBIO_v1_literature_cited.pdf` and `Metadata.pdf`, the files of the figshare deposit 10.6084/m9.figshare.4644424.
Licence: unknown; owner to check https://doi.org/10.6084/m9.figshare.4644424 (the licence is not stated in the files, the README or the bib; the 2026-10-02 audit read CC BY 4.0 on the figshare record). All four files are tracked; see sources/LICENSES.md.
Source label: `AmphiBIO`.
