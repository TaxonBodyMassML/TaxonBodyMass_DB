# Pipeline

The pipeline is written in R. The main entry point is `R/RunMe.r`, which orchestrates all steps.

## Step 1 — Per-source parsing

Each source has its own script at `sources/databases/<SourceName>/BodyMass_<SourceName>.r` that reads raw data files, extracts taxon names and body masses, converts units to grams, and saves a cached `.Rdata` file to `sources/Rdata/`. Sources that report dry, ash-free dry or carbon mass are converted to wet grams with the group-specific factors in `R/library/mass_conversion.r` (`ToWetMass()`); each such script's `README.md` states the mass type reported by the source and the conversion group applied, and the CiteIDs of the conversion references are appended to the record's `source_mass` label (e.g. `Kendall_etal_2019; Studier_1992`) so they are cited alongside the source. Rows that the source itself flags as imputed, genus-averaged or taken from another species are removed in the parse scripts (`DropImputed()` in `R/library/helpers.r`) and logged to `audit/imputed_rows.csv` together with the records the raw-name rules of step 2 drop (life stages and small size classes) and the entries of the live download frames, which the download scripts save in `audit/imputed_rows_live.csv` (issue #40; the file is written after step 2, only when the parse scripts ran, and is the same whatever the download flags were); each source's `README.md` records this in an `Imputed rows:` line, which `R/library/check_source_docs.r` checks at every run, together with a `Licence:` line stating the terms of the folder's raw files (`Licence: <class> (<where stated>; <URL>). <note>`, or `Licence: unknown; owner to check <URL>`), which must agree with the manifest `sources/source_files.csv` (a folder without the line or without a manifest row stops the run, an unknown licence is warned about and written to `reports/warnings_licences.md`; exercised without network access by `Rscript R/library/tests/test_licence_docs.R`). These cached files are git-ignored and regenerated by setting `recompile = TRUE` in `RunMe.r`.

## Step 2 — Taxon name cleaning

Applied uniformly to every source before merging. The rule of the database is that a cleaned name has two parts, `Genus_species`, or one, `Genus`, and nothing but letters; every raw name that does not already look so is reduced to that form by an explicit rule, and a raw name no rule covers stops the run (issue #38):

- **`R/library/fix_formatting.r`** — `FixFormatting()` first normalizes encoding (only strings that are not valid UTF-8 are converted from Latin-1; diacritics are then transliterated to ASCII, so `Nausithoë rubra` becomes `Nausithoe_rubra`) and strips the sex signs ♀/♂, keeping the record as the species' value. It then parses the name into its bracket groups and tokens and applies the tracked vocabulary `audit/raw_name_patterns.csv` (one regex per row with its `scope`, `class`, `action`, `note` and date; see `audit/README.md`):
  - a capitalised word in brackets between genus and epithet is a **subgenus** and is removed
  - **sex** marks, **form, strain, region** annotations are stripped and the record kept
  - Brose soil-web **size classes**: medium and larger ones are stripped and kept; small ones (non-adult) are dropped via `DropImputed()`
  - a **species group** marker is stripped and the record credited to the nominal species
  - a **synonym** or common name in brackets after the binomial and an **authority** are stripped
  - a lowercase third token is a subspecies or variety and folds into the species (**trinomial** -> binomial)
  - a **placeholder** epithet or identification **qualifier** leaves the function as a marker (`Genus_sp`, `Genus_cf`, etc.), which `fix_nontaxa.r` removes
  - **life-stage** annotations make the record a non-adult and it is dropped via `DropImputed()`
  - **hybrids** and **ambiguous alternatives** are cut at the separator and credited to the first name written
  - **symbols** that cannot occur in a Latin name are removed

  Every name a rule touched is listed by class and source in `reports/warnings_raw_names.md`; a bracket group or trailing token no rule covers is an **error** that stops the run. Exercised by `Rscript R/library/tests/test_raw_name_rules.R` and `test_fix_formatting_encoding.R`.

- **`R/library/fix_misspellings.r`** — corrects known misspellings.

- **`R/library/fix_nontaxa.r`** — removes placeholder identifiers, functional-group labels and common names that food-web compilations use as names. Exercised by `Rscript R/library/tests/test_nontaxa_labels.R`.

- **`R/library/filter_extinct.r`** — removes extinct species (list in `audit/extinct_taxa.csv`, compiled by hand with `R/library/build_extinct_taxa.r` from the status columns of MOM v10.2, PHYLACINE 1.2 and AVONET).

- **`R/library/check_taxon_names.r`** — three guards. `CheckRawNames()` runs right after `FixFormatting()` and stops the run on unhandled raw names. `CheckTaxonNames()` runs after the chain and stops the run if any cleaned name is not `Genus_species` or `Genus`. `CheckSheetTaxa()` runs in step 3 on the rows of the lab Sheet. Exercised by `Rscript R/library/tests/test_taxon_name_guard.R` and `test_raw_name_rules.R`.

## Step 3 — Google Sheet override

Lab-curated values (`BM_data` tab) take priority over the compiled sources. The tab is read from its tracked copy `sources/BM_data_snapshot.csv` (`R/library/sheet_snapshots.r`): a run with `DataSheets = TRUE` at the top of `RunMe.r` first downloads the three Sheet tabs the pipeline uses and rewrites their copies; with `DataSheets = FALSE` (the committed default) the copies are read as they are, no Google token is needed. The outputs are the same whichever mode wrote the copies.

Sheet rows are split by the underscore rule (`R/library/sheet_override.r`, issue #57): a species-level row (`Genus_species`) replaces all compiled records of that species; a genus-level row (a bare `Genus`) replaces the sources' genus-only rows of that name and joins the genus-only path of step 6. Exercised by `Rscript R/library/tests/test_sheet_override.R`.

## Step 4 — Taxonomy enrichment and autotroph removal

Every unique name is resolved once to an accepted species and its full kingdom-to-species classification through GBIF, NCBI, WoRMS, Catalogue of Life, ITIS and Wikidata in turn, with a final GBIF backfill of missing higher ranks (`R/library/enrich_taxonomy.r`; details in `sources/passes/enrichment_pipeline.md`). Results are cached in `sources/enrich_cache.Rdata` so re-runs only query new names. Manual corrections live in `R/library/fix_taxonomy_ranks.r`.

`R/library/filter_autotrophs.r` then removes autotrophs: the kingdoms Plantae, Viridiplantae and Fungi; predominantly photosynthetic phyla; and a curated list of photosynthetic or mixotrophic dinoflagellate and euglenid genera. Heterotrophic protists are retained.

## Step 5 — Merging, de-duplication and range filter

Within each source, body masses are summarised as the geometric mean across records resolving to the same accepted species. Records are put in a fixed order before this pass (`OrderForPass1()` in `R/library/helpers.r`) to ensure bit-reproducibility (issue #53). Exercised by `Rscript R/library/tests/test_output_stability.R`.

The same datum often reaches the database through several compilations. `R/library/dedupe_sources.r` collapses copies before Pass 2 (issue #5) using two layers: the hand-maintained dependency registry `Bib/source_dependencies.csv` (tolerance-based collapse), and a blind rule that collapses values identical to at least three significant digits in any two sources. Matching values form a component per species; the registry ancestor (or the lowest-priority sibling) is kept and the others recorded as `dropped<kept` in `source_dependencies`. `reports/dedupe_summary.md` lists every edge with the species it shares and collapsed.

Across sources, the independent values are combined as the arithmetic mean (owner decision 2026-10-03, issue #16). `log10_range` records the spread of the values; species whose values disagree by more than one order of magnitude (`log10_range > 1`) are removed (`R/library/remove_high_range.r`).

**Record-level range rule** (issue #34; `R/library/exclude_discordant.r`, run between de-duplication and the cross-source mean): for species whose independent values span more than an order of magnitude, `ExcludeDiscordantValues()` judges each by a cascade and excludes one value (or one side) when the cascade singles it out:

- **(A) leave-one-out** (`loo_unique`): exactly one value whose exclusion brings the rest within 1 log10, provided the rest span at least two evidence groups
- **(A2)** several such values: the one of lowest trust tier (`tier_tiebreak`), else the one farthest from the median (`distance_tiebreak`)
- **(D) two values or one evidence group vs. one**: the lower-trust side when the tiers differ (`two_value_tier`)
- **(E)** otherwise nothing is excluded and the species falls to the `log10_range > 1` filter as before

Trust tiers come from the `value_tier` column of `Bib/source_provenance_classes.csv`: 1 for compiled or measured adult values (default), 2 for maxima-based or allometric sources, 3 for single specimens, individuals, converted or web-level values. A value converted from dry/ash-free dry/carbon/energy mass is tier 3 whatever its source's tier.

An excluded value stays in `source_mass` and `n`, is left out of `mass_g`, `n_independent` and `log10_range`, and is named in `sources_excluded`. `reports/excluded_records.csv` is the live list of a run's exclusions; the register `audit/flagged_species.csv` holds the append-only adoption batch. Exercised by `Rscript R/library/tests/test_exclude_discordant.R`.

## Step 6 — Genus-level aggregation

`TaxonBodyMass_GenusLevel.csv` gives, for every accepted genus, the arithmetic mean of the cross-source means of its species (step 5) and of its genus-only record, each with the weight of one value. A genus-only record is a value for an organism identified to genus only, measured or compiled as the source reports it.

Every bare name is resolved once at genus rank through the accepted genera of the enrichment cache and the GBIF backbone exact-name lookup, with class/order/family hints where available. Synonyms and misspellings fold into the accepted genus; names of ranks above genus (family, order, class usages) leave the table. The answers are cached as `genus_cache` in `sources/enrich_cache.Rdata`. Names no stage resolved are listed in `reports/warnings_taxonomy.md` and their rows are dropped.

Genus-only records are judged against the genus's species cross-source means by the same record-level range rule as step 5 (`ExcludeDiscordantGenusRecords()`). `reports/genus_only_records.md` lists the names resolved above genus, the autotroph genera removed, the fuzzy matches and homonym choices, the synonyms folded, the values collapsed as copies, and the genus-only records more than an order of magnitude from the genus's species values. Exercised by `Rscript R/library/tests/test_genus_only_records.R`.

## Step 7 — Citations and provenance (issue #1)

`R/RunMe.r` section 8 reads both bibliographies, the hand-curated `Bib/TaxonBodyMass_Citations.bib` and the generated `Bib/TaxonBodyMass_PrimaryCitations.bib` (built by `R/library/citations/run_citations.r --bib`; never edited by hand), and both citation tabs of the lab Sheet from their tracked copies. Sheet rows whose key is in neither bib are listed in `reports/warnings_citations.md`.

`TaxonBodyMass_Provenance.csv.gz` links every species of `TaxonBodyMass.csv` to its source labels and, where a source's reference list has been ingested and verified (`sources/databases/<Src>/primary_references.csv`), to the study that measured the animal, with the hop and provenance type of each reference. Records without a reference get the default of the registry `Bib/source_provenance_classes.csv`. The tooling, its decision rules and its hallucination-robustness rules are described in `R/library/citations/README.md`; `RunMe.r` sources only its offline part and never calls Crossref, OpenAlex or Scite.

## Source dependency registry

`Bib/source_dependencies.csv` records which sources copy or derive their body masses from which others. Columns: `child_label`, `parent_label`, `parent_in_db`, `relation` (`copies`, `via`, `shared_primary`, `derived_same_input`, or `provenance_only`), `tol_log10`, `priority`, `status`, `n_rows_child`, `evidence` and `added`. `LoadSourceDependencies()` stops the pipeline when a child or an in-database parent is not a label of any source frame, when an external parent is one, on a cycle, or on conflicting priorities.

Tested by:

```bash
Rscript R/library/tests/test_dedupe_sources.R
```

`Rscript R/library/dedupe_audit.r [--before <earlier TaxonBodyMass.csv>]` replicates Pass 1, the de-duplication and Pass 2 from `sources/Rdata` and checks the released CSV against it.

## Run-stop conditions

The run stops before any cached frame is loaded (step 2) when:

- **a parse script fails** (`recompile = TRUE`) — every failure is printed as an `ERROR:` line; fix the scripts and rerun.
- **a cached frame was not rewritten** (`recompile = TRUE`) — a frame in `sources/Rdata/` is older than the loop (orphan or script ran without saving). Delete the orphan or fix the script.
- **an expected frame is missing** (whatever `recompile` is) — `R/library/check_cache.r` names the flag to set for each missing frame (`recompile`, `DataRetrieve`, `DataVertNet` or `DataFishbase`).

These guards are exercised by:

```bash
Rscript R/library/tests/test_recompile_guard.R
```

`CheckImputedLive()` warns (without stopping) when a live frame in `sources/Rdata/` is not the file whose download saved its rows in `audit/imputed_rows_live.csv`; rerun with that frame's flag set to `TRUE` to refresh. Exercised by:

```bash
Rscript R/library/tests/test_imputed_live.R
```
