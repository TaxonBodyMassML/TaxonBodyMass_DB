# All Outputs

## Primary outputs

| File | Description |
|---|---|
| `TaxonBodyMass.csv` | One row per accepted species. Columns: `genus`, `species`, `taxon` (a representative input name), `taxon_provided` (all input names, `;`-separated), `log10_range` (spread of the independent per-source values: log10 of the largest over the smallest, six decimals), `mass_g` (grams, arithmetic mean of the independent values, four significant figures), `source_mass` (`;`-separated labels of every contributing source and conversion reference), `n` (records in all sources), `n_sources` (per-source values, the VertNet dumps counted once), `n_independent` (values entering the mean), `source_dependencies` (values collapsed as copies, `dropped<kept` pairs `;`-separated), `n_excluded` and `sources_excluded` (per-source values the record-level range rule left out of the mean), `kingdom`, `phylum`, `class`, `order`, `family`, `taxonomy_source`, `gbif_confidence`, `gbif_status`, `gbif_family`, `gbif_order`, `species_changed` |
| `TaxonBodyMass_GenusLevel.csv` | One row per accepted genus (pipeline step 6): `mass_g`, `source_mass`, `n` and `n_independent`. Names of ranks above genus, unresolved bare names and autotroph genera are excluded |
| `TaxonBodyMass_Provenance.csv.gz` | One row per species × source label × reference for the species of `TaxonBodyMass.csv` (pipeline step 7, issue #1): `genus`, `species`, `taxon`, `source_mass` (one label), `source_bibcite`, `origin` (`pipeline` or `BM_data`), `hop` (0: the source measured the animal or a conversion factor; 1: the source cites the reference; 2: through an intermediate compilation), `via_cite_id`, `ref_role`, `provenance_type`, `primary_cite_id`, `primary_bibcite`, `primary_doi`, `match_status`, `n_records`, `record_status` (`kept` or `excluded_<rule>`). Gzipped CSV, deterministic (no timestamp); rows in a fixed order |

## Audit and QC files

| File | Description |
|---|---|
| `audit/raw_name_patterns.csv` | Vocabulary of raw-name rules `FixFormatting()` applies (pipeline step 2): `pattern`, `scope`, `class`, `action`, `note`, `added`; maintained by hand, validated on loading |
| `audit/imputed_rows.csv` | Log of rows dropped as imputed, life stages or small size classes, one row per `DropImputed()` call; rewritten at every run with `recompile = TRUE` |
| `audit/imputed_rows_live.csv` | The `DropImputed()` entries of the four live download frames; saved by the download scripts and merged into `audit/imputed_rows.csv` at every run |
| `audit/extinct_taxa.csv` | The extinct-taxa list applied by `RemoveExtinct()` (pipeline step 2), rebuilt by hand with `R/library/build_extinct_taxa.r` |
| `audit/flagged_species.csv` | Append-only register of values excluded by the record-level range rule and single-value rescues (one batch per adoption event; `audit/README.md`) |
| `sources/source_files.csv` | Licence manifest: one row per tracked file under `sources/databases/` and `sources/conversion_factors/` plus one `live` row per source downloaded at run time; sizes and hashes regenerated by `Rscript R/library/licence_manifest.r` |
| `sources/LICENSES.md` | Generated from the manifest: the scope of the repository licence, attribution texts, carve-outs, publisher files and the "unknown; owner to check" list |

## Reports (regenerated at every run)

| File | Description |
|---|---|
| `reports/excluded_records.csv` | Live list of the values the record-level range rule excluded: `level`, `genus`, `species`, `taxon`, `source_label`, `source_mass`, `mass_g`, `n`, `value_tier`, `rule`, `distance_log10`, `copy_of`, `n_kept`, `single_value_rescue`, `kept_mass_g`, `kept_values` |
| `reports/dedupe_summary.md` | Per-edge and residual summary of the de-duplication |
| `reports/genus_only_records.md` | How the genus-only records resolved at genus rank: names above genus and autotroph genera excluded, fuzzy matches and homonym choices, synonyms folded, values collapsed as copies, and records more than an order of magnitude from the genus's species values |
| `reports/warnings_raw_names.md` | Every raw taxon name `FixFormatting()` changed or classified, by class and source, with names dropped and names no rule covers |
| `reports/warnings_taxonomy.md` | Every cleaned name no enrichment stage resolved (with sources and row counts), Catalogue of Life resolutions, kingdom conflicts corrected before the autotroph filter |
| `reports/warnings_mass_values.md` | Mass-value QC warnings, including the single-value rescues |
| `reports/warnings_name_change.md` | Taxa whose accepted name changed from a prior run |
| `reports/warnings_licences.md` | Source folders whose licence is unknown, non-commercial and share-alike carve-outs, README `Licence:` lines that disagree with the manifest, and folders without the line or absent from the manifest |
| `reports/warnings_citations.md` | Citation-step checks: totals, problems (bib keys, CiteID rows, accepted references without DOI or bib entry), Sheet rows whose Bibcite is in neither bib, labels without a CiteID row, and per-source coverage of the provenance table |

## Reproducibility

The tables are reproducible byte for byte: for a given cache (`sources/Rdata`, `sources/enrich_cache.Rdata`) and given tracked copies of the lab Sheet tabs, two runs write identical `TaxonBodyMass.csv`, `TaxonBodyMass_GenusLevel.csv`, `TaxonBodyMass_Provenance.csv.gz`, `reports/excluded_records.csv`, `audit/imputed_rows.csv` and `Bib/TaxonBodyMass_CitationCiteIDs.csv`, because the records are put in a fixed order before the first averaging pass and the derived floating-point columns are rounded at write time (`log10_range` to six decimals, `mass_g` to four significant figures; issue #53). The reports under `reports/` differ between runs only in their timestamp line.
